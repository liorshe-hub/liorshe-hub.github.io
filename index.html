Sudoku Solver (Single File)

Paste a 9×9 grid. Use . or 0 for empty cells. You can enter 9 lines or a single line of 81 characters. Output matches the typical 01‑Edu format: each solved row on its own line, numbers separated by spaces; prints Error if invalid or unsolvable.

Tip: You can paste the 01‑Edu command‑line string (81 chars like "..4..3..9..."). The tool will normalize it.
